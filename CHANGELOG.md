# Changelog

All notable changes to HuoBTC Exchange will be documented in this file.

## [1.0.0] - 2024-02-05

### 🎉 Initial Release

#### Core Features
- Complete cryptocurrency exchange platform
- Spot trading with real-time order book
- Leverage trading (up to 100x)
- Seconds contract trading (30s/60s/120s)
- Real-time K-line charts with multiple timeframes

#### Wallet Integration
- TronLink wallet support
- TokenPocket wallet support
- BitKeep wallet support
- OKX Wallet support
- Web3 signature authentication

#### Multi-Chain Support
- TRC20 (TRON network)
- ERC20 (Ethereum network)
- BEP20 (BSC network)

#### Internationalization
- English (en)
- Simplified Chinese (zh)
- Traditional Chinese (zhHant)
- Japanese (ja)
- Korean (ko)

#### Customer Service
- Real-time chat system
- Image upload support
- Admin chat management

#### Admin System
- User management & KYC
- Deposit/Withdrawal review
- Risk control settings
- Payment configuration
- Telegram notifications

#### Mobile Support
- Responsive web design
- Android APK (Capacitor)
- PWA support
